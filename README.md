# FontColle

A Google Fonts alternative that filters by what fonts.google.com can't: real
OpenType features, variable-font axes, weight/width steps, writing systems,
languages, and color vs. monochrome. Preview any weight or named instance live,
edit the specimen text inline, and save favorites. We own only the metadata
index and the UI — every font file and download redirects to Google Fonts.

## Stack

- **TanStack Start** (React 19, file-based routing) on **Cloudflare Workers**
- **Cloudflare D1** for the font metadata index, via **Drizzle ORM**
- **Tailwind CSS v4** + **shadcn/ui** (Base UI primitives)
- **Vite 8** build through the Cloudflare plugin
- **Biome** for lint + format
- A **Python harvester** (`scripts/harvester`) that builds the dataset from the
  Google Fonts catalog and `gflanguages`.

## Development

```bash
pnpm install
pnpm dev          # vite dev server on :3000
```

`pnpm check` runs Biome (with `--write`) then `tsc --noEmit`; run it before
committing. `pnpm build` produces the Workers bundle in `dist/`.

| Script | What it does |
|---|---|
| `pnpm dev` | Local dev server |
| `pnpm build` | Production build (`scripts/build.mjs` wraps `vite build`) |
| `pnpm check` | Biome fix + typecheck |
| `pnpm test` | Vitest |
| `pnpm db:apply:remote` | Apply Drizzle migrations to the remote D1 |
| `pnpm db:seed:remote` | Seed the remote D1 from `src/data` |

The app reads fonts from D1 in production. Both dev and deploy use the **remote**
D1 (`font-finder-d1`); use the `:remote` db scripts.

## Data pipeline

The static dataset under `src/data` (`fonts.json`, `languages.json`,
`scripts.json`) is generated by the harvester, then converted to seed SQL:

```bash
python3 scripts/harvester/harvest.py          # fetch + parse font files
python3 scripts/harvester/to_dataset.py ...   # -> src/data/*.json
pnpm db:seed:gen                              # -> seed SQL
pnpm db:seed:remote                           # load into remote D1
```

`langcov.py` derives language/script coverage and region groupings from
`gflanguages`.

## Project layout

```
src/
  routes/            file-based routes (index list, $fontId detail)
  components/         FontCard/Row/Grid, FontTraits, preview dock
    filter/          sidebar filter sections
    ui/              shadcn/ui primitives (generated)
  lib/
    fonts/           filter, sort, traits, preview-style, loader, labels…
    filter/          shared filter context
    preview/         shared preview-text context
    db/              Drizzle schema + client
  data/              generated dataset (fonts/languages/scripts JSON)
scripts/harvester/   Python dataset pipeline
```
